# Как сделать, чтобы мобильная версия выглядела так же, как на компьютере

## Главное (почему цвета «не те»)

Сайт — **один и тот же** для Mac и iPhone. Отличается только **ширина экрана** (на телефоне нет бокового фото, блоки по центру).

**Настройки из панели «Настройка дизайна» сохраняются в браузере**, в `localStorage`, ключ `wedding-theme-vars`.

| Где открыли сайт | Где лежат ваши цвета |
|------------------|----------------------|
| Chrome/Safari на Mac | В памяти браузера на Mac |
| Safari на iPhone | **Отдельно**, в памяти Safari на iPhone |

То есть настроили на компьютере → на телефоне **по умолчанию снова стандартные цвета**, пока вы не повторите настройку на iPhone **или** не опубликуете сайт с зафиксированными цветами в коде.

Это не баг вёрстки — так устроены локальные сайты без облака.

---

## Что должно совпадать само (без действий)

Если на **одном устройстве** открыть и Mac, и телефон с одной ссылкой — не будет: у каждого браузера своя память.

Если на **iPhone** вы уже выставили те же ползунки/цвета в панели, что на Mac, должны совпадать:

- фон страницы (`--linen`);
- фон и текст каждого блока (обращение, локация, дресс-код, программа, организация, RSVP, финал);
- главный экран (hero): фон, «Наша свадьба», имена, дата, таймер, кнопки.

Мобильная вёрстка **не должна** подменять цвета — только расположение (без фото слева, заголовки по центру, текст по ширине).

## Пошагово: одинаковый вид на iPhone после настройки на Mac

### Вариант А — скачать и загрузить файл (рекомендуется)

На сайте в панели **«Настройка дизайна»** → блок **«Перенос на другой телефон / браузер»**:

1. **На Mac** (после настройки цветов): нажмите **«Скачать настройки»** — получите файл `wedding-design-settings-….json`.
2. Перешлите файл на iPhone (AirDrop, Telegram, «Файлы»).
3. **На iPhone**: откройте сайт → «Настройка дизайна» → **«Загрузить настройки»** → выберите этот JSON.
4. Появится сообщение «Настройки загружены и применены» — цвета и шрифты как на Mac.

В файл также попадают тексты из панели (надпись, дата, обращение), если вы их меняли там.

### Вариант А2 — зафиксировать только мобильную версию

См. **[MOBILE-THEME-LOCK.md](MOBILE-THEME-LOCK.md)** — кнопка **«Зафиксировать мобильную тему»** в панели (на узком экране). Файл `mobile-theme-lock.json` в проекте задаёт вид на iPhone для всех гостей.

### Вариант Б — зафиксировать дизайн в коде (лучше перед отправкой гостям)

Попросите разработчика (или в чате Cursor):

> «Зафиксируй текущие настройки темы из localStorage в `styles.css` (в `:root` и переменных блоков), чтобы на всех устройствах были одинаковые цвета без панели дизайна. Панель можно оставить только для нас или убрать на продакшене.»

Тогда гости на любом телефоне увидят **ваш** дизайн без повторной настройки.

### Вариант C — после публикации в интернет (Netlify / GitHub Pages)

1. Сначала на Mac доведите дизайн до финала.
2. Зафиксируйте цвета в CSS (вариант Б) **или** один раз настройте и экспортируйте тему в файл (если добавят кнопку «Экспорт темы»).
3. Выложите сайт по постоянной ссылке `https://...`.
4. Гости открывают ссылку — у всех один и тот же вид.

## Промпт для Cursor / разработчика

Скопируйте и отправьте, когда будете готовы к доработке:

```
Нужно, чтобы свадебный сайт wedding-invite-site на iPhone и iPad 
выглядел с ТЕМИ ЖЕ цветами, шрифтами и размерами, что на десктопе 
после настройки в панели «Настройка дизайна».

Требования:
1. Не использовать размытый фон hero под секциями на мобильных — 
   только сплошные цвета из CSS-переменных (--invite-bg, --details-bg и т.д.).
2. Главный экран (hero) без лишнего blur — только существующие анимации лучей.
3. Мобильная вёрстка: без бокового фото; заголовки секций по центру; 
   основной текст по ширине (justify).
4. Все цвета/шрифты секций — только из theme-переменных, как на desktop.
5. Добавить способ «зафиксировать» тему для гостей: 
   кнопка «Экспорт настроек» → JSON и «Импорт» на другом устройстве, 
   ИЛИ запись финальной темы в :root в styles.css при публикации.

Сейчас тема в localStorage (ключ wedding-theme-vars) — на телефоне 
отдельная копия. Нужно понятное решение для одинакового вида у гостей.
```

## Чего не делать

- Не ожидать, что `localhost` на Mac и iPhone **сами** подхватят настройки с компьютера.
- Не править цвета только в мобильном CSS отдельно от desktop — иначе снова разъедутся.
- Не использовать полупрозрачные/размытые фоны секций на мобильных, если нужен ровный печатный вид.

## Проверка на iPhone

1. Mac и iPhone в одной Wi‑Fi, сервер:  
   `python3 -m http.server 8080 --bind 0.0.0.0`
2. На iPhone: `http://IP-Mac:8080`
3. Сверьте блок «Локация», «Программа дня» с Mac **после** одинаковой настройки панели на обоих устройствах.

Если после одинаковой настройки что-то всё ещё отличается — опишите блок и пришлите скрин Mac + iPhone.
