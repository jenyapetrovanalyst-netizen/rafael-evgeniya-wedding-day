# Фиксация мобильной версии

> **Актуальный freeze всего сайта (desktop + mobile):** см. [`SITE-FREEZE.md`](./SITE-FREEZE.md) (2026-08-01).

Чтобы цвета, шрифты и размеры на телефоне **не сбрасывались** при правках кода и совпадали у всех гостей на мобильной ширине.

## Как это работает

На экранах **≤1024px** при загрузке подмешиваются (снизу вверх):

1. `mobile-theme-lock.json` из проекта (база для всех)
2. `wedding-mobile-theme-lock` в localStorage (если вы нажимали «Зафиксировать» на этом устройстве)
3. `wedding-theme-vars` — ваши правки из панели «Настройка дизайна»

На **широком экране** (Mac) файл блокировки не применяется — только обычная тема из панели.

## Нужно ли что-то делать вам?

**Обычно нет.** Файл `mobile-theme-lock.json` уже лежит в проекте — на телефоне гости увидят эту тему без панели и без ваших действий.

Кнопка **«Зафиксировать мобильную тему»** нужна только если вы **снова** меняете цвета/шрифты в панели на iPhone и хотите сохранить именно эту новую версию в проект.

## Что видит гость

Гость открывает **опубликованную ссылку** `https://…` (не `localhost`). На ширине телефона подставляется `mobile-theme-lock.json` из сайта, затем — только если у гостя нет своих сохранений — ничего (панель гостю не обязательна).

## Сброс

- **Сбросить все настройки** в панели — очищает `wedding-theme-vars`, не трогает `mobile-theme-lock.json` в проекте.
- Чтобы убрать фиксацию с телефона: удалите ключ `wedding-mobile-theme-lock` в Safari (Настройки → Дополнения → Данные сайтов) или очистите данные сайта.
