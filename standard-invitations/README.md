# Standard invitations

Готовые **открытки-приглашения** для отправки в мессенджеры до публикации основного сайта.

## Открыть редактор

Локально (тот же сервер, что и сайт свадьбы):

- На Mac: [http://localhost:8080/wedding-invite-site/standard-invitations/](http://localhost:8080/wedding-invite-site/standard-invitations/)
- С iPhone в той же Wi‑Fi: `http://192.168.0.18:8080/wedding-invite-site/standard-invitations/` (подставьте IP Mac: Системные настройки → Сеть)

Запуск сервера в терминале:

```bash
cd "/Users/genj2004/Desktop/analyst 2026/wedding-invite-site"
python3 -m http.server 8080 --bind 0.0.0.0
```

Или двойной клик по `index.html` (кнопка «Скачать PNG» может не сработать без сервера).

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Редактор + превью открытки |
| `card.css` | Вёрстка открытки |
| `editor.js` | Текст, шрифты, цвета, сохранение в браузере |
| `assets/card-background.jpg` | Фон — оливковая текстура (из пина 2) |
| `fonts-pinterest.css` | Шрифты с пинов: Good Vibes, Min Sans, Nyght Serif, Transforma, Florisel, Free Serif, Ossem |

## Шрифты и цвета

По умолчанию — фото с ромашками, кремовый текст, **Good Vibes** + **Min Sans** (пин 1).

Кнопки **«Пин 1 / 2 / 3»** подставляют пары шрифтов с ваших референсов.  
**«Цвета и шрифты с сайта»** — олива/крем как на свадебном сайте.

## Отправка гостям

1. Подправьте текст в панели слева (настройки сохраняются в браузере автоматически).
2. **Скачать PNG** — файл для WhatsApp / Telegram (~1600 px по ширине, как в превью).
3. Или сделайте скриншот открытки на телефоне.

Текст по умолчанию — «Совсем скоро… ссылка на сайт» (можно менять в любой момент).

### PNG — важно

- Открывать только через **локальный сервер** (`http://…`), не двойным кликом по `index.html`.
- Логика скачивания зафиксирована: см. **`PNG-EXPORT.md`** (режим `card--png-capture`, spacer для подписи).
- После скачивания превью **не должно** меняться; если меняется — обновите страницу и сообщите.
