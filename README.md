# Сайт-приглашение «Наша свадьба»

Проект собран по концепции из файла `Сайт _Наша свадьба_ 2026.md`.

## Структура проекта

- `index.html` — структура всех экранов.
- `styles.css` — стили в заданной палитре и типографике.
- `content.js` — весь редактируемый контент (имена, тексты, тайминг, ссылки, палитра).
- `script.js` — логика таймера, прелоадера, анимаций и RSVP-формы.

## Как редактировать сайт

Главное правило: в 90% случаев меняйте только `content.js`.

Что именно можно менять:
- `siteContent.couple` — имена и монограмма.
- `siteContent.wedding` — дата, время, сбор гостей.
- `siteContent.location` — площадка, адрес, ссылка на карту, контакт.
- `siteContent.timeline` — программа дня.
- `siteContent.dresscode` — текст и цвета.
- `siteContent.organization` — блок про цветы, подарки, контакты.
- `siteContent.rsvp` — дедлайн, варианты ответов, текст после отправки.
- `siteContent.final` — финальный текст и декоративное «эхо».

## Как открыть локально

Откройте `index.html` в браузере.
