# Текстуры палитры дресс-кода

На **всех** ширинах в кружках — **фото драпированного шёлка** (JPG 640×640), не плоский `hex`. `hex` — запасной фон, если фото не загрузится.

Чтобы заменить образец:

1. Положите квадратное фото (~400–800 px) как `swatch-NN-название.jpg`.
2. Обновите путь в `content.js` → `dresscode.palette[].image`.

Текущие файлы: `swatch-01` … `swatch-10` (10 цветов). Порядок в `content.js` — по группам оттенков (светлые → зелёные → розовые → коричневые). Мокко и эспрессо — атласная текстура в том же стиле, что остальные кружки.
