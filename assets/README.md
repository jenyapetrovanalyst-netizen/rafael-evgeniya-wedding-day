# Фото для сайта

## Главный экран (фон на весь экран)

| Файл | Назначение |
|------|------------|
| `hero-main.png` или `hero-main.jpg` | Основное фото главного экрана (сейчас: `hero-main.png`, 1672×941) |
| `hero-main@2x.jpg` | Опционально: версия в 2× для Retina (если добавите — обновите `srcset` в `index.html`) |

Сайт сам подхватит `@2x`, если положить файл с этим именем в эту папку.

### Как получить максимальное качество

1. Возьмите **оригинал с телефона/камеры**, не пересланный в Telegram (мессенджеры сжимают фото).
2. Экспортируйте или обрежьте до **не уже 1920 px по ширине** (лучше 2400–3000 px).
3. Сохраните как JPG с качеством **85–92%** или как WebP (при необходимости добавим в код).
4. Положите в эту папку:
   - `hero-main.jpg` — версия ~1200–1600 px по ширине;
   - `hero-main@2x.jpg` — версия в 2 раза больше (для Retina и широких мониторов).
